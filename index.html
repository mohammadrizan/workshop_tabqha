Koding Next Batam

Coding & AI Education Program

Empowering SMA Kristen Tabgha through student Python programming workshops and hands-on teacher training in Computer Vision & Artificial Intelligence.

Delivered by Koding Next Batam, this initiative divided focus into two distinct objectives: establishing core Python coding skills for high school students, and training educators on using AI tools like Teachable Machine and Scratch Lab to build intelligent recognition systems.
